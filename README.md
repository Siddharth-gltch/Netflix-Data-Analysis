# 📊 Netflix Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on Netflix Movies and TV Shows dataset to uncover trends, patterns, and insights.

## 🛠️ Tools & Technologies

* Python (Pandas, NumPy)
* Matplotlib & Seaborn
* Jupyter Notebook

## 📊 Key Analysis Performed

* Data Cleaning and Preprocessing
* Content Distribution (Movies vs TV Shows)
* Country-wise Content Analysis
* Year-wise Growth of Content
* Genre Analysis

## 📈 Key Insights

* Movies dominate Netflix content compared to TV Shows.
* The United States produces the highest number of titles.
* Significant growth in content was observed after 2015.
* Drama and International genres are the most common.

## 📂 Dataset

Netflix Movies and TV Shows Dataset (Kaggle)
